# Story bank for blog posts

Each weekly post needs 2-3 real stories from the owner's note posts (https://note.com/hide3399). This file tracks which stories are still unused so topics do not run out.

Last checked note posts up to: 2026-11-08 (33 posts)

## How to use (every weekly run)
1. Check note for posts published after the date above. Add each one below (key, date, one-line story, which theme it feeds) and update the date.
2. Pick the next theme from "Theme queue" with status `ready`. Mark it `scheduled YYYY-MM-DD` and mark its note posts `used`.
3. A note post marked `used` may be used once more only with a clearly different angle (another season, another question a traveller asks). Never repeat the same anecdote in two posts.
4. Other real sources, in this order, when note is thin: guest review texts in the Notion page "Kindle素材ログ" (guests by country only), tour notes in the Notion "Daily Log — Hide", the owner's own existing blog posts. Never invent experiences.
5. If fewer than 4 themes are `ready`, say so in the run's push notification: "ネタ残り◯本。次のツアー後にnoteを1本書くか、Daily Logに一言メモを残してください". Name which tours have no unused stories.
